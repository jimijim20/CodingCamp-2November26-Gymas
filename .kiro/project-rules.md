# To-Do List Life Dashboard

## Technical constraints

- Use HTML for structure, CSS for styling, and vanilla JavaScript for behavior.
- Use browser localStorage for client-side data.
- Build a standalone web app with no backend, framework, or build step.
- Support modern Chrome, Firefox, Edge, and Safari.
- Use one CSS file in `css/` and one JavaScript file in `js/`.
- Keep the UI simple, readable, and responsive, with no required test setup.

## Required features

- Show the local time, date, and a time-based greeting.
- Provide a 25-minute focus timer with Start, Stop, and Reset.
- Allow users to add, edit, complete, and delete tasks.
- Provide quick links to favorite websites.
- Save tasks and quick links in localStorage.

## Selected challenges

- Custom name in greeting.
- Prevent duplicate tasks.
- Sort tasks.

## Theme

- Use `rgb(245, 197, 24)` as the main accent.
- Use black text and a readable layout.
